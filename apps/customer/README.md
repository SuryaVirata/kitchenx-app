# @kitchenx/customer

KitchenX customer app for restaurants, bakeries, shops and other F&B businesses. Targets iOS, Android and Web (React Native Web).

```bash
pnpm --filter @kitchenx/customer start
pnpm --filter @kitchenx/customer web
```

- `src/app/` routes (thin)
- `src/features/` one folder per feature; each README lists its PRD requirement IDs
- `src/shell/` providers, startup, guards
- `src/lib/` app-specific instances of shared packages
- `e2e/` Maestro flows
